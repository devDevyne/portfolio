# 업무 흐름을 이해하고 운영에 필요한 기능을 만드는 개발자

Java/Spring 기반 웹 서비스 개발을 중심으로 React 프론트엔드 개발과 리딩까지 경험한 풀스택 웹 개발자입니다. 상가 운영·관리 플랫폼, 환경 데이터 플랫폼, 기업 홈페이지와 관리자 시스템에서 API·데이터베이스·웹 화면을 연결하는 업무를 수행했습니다.

기능 구현에 앞서 기존 코드와 데이터 흐름을 분석하고, 업무 정책과 예외 상황을 구체화합니다. 결제 승인 후 내부 처리가 실패하는 상황, 예약 이후 수신 동의가 바뀌는 상황, 센서 데이터가 누락되는 상황처럼 정상 흐름만으로 설명되지 않는 조건을 설계에 반영해 왔습니다.

## 핵심 역량

### 업무 정책을 데이터와 처리 흐름으로 구체화

결제·예약·계약·알림 기능에서 검증 조건, 상태 전환, 실패 처리와 이력 보존 기준을 정리하고 구현했습니다. FigJam으로 데이터 관계와 요청 흐름을 설명하고, 검토 과정에서 합의한 정책을 개발에 반영했습니다.

### React 공통 구조 설계와 팀 개발 지원

페이지 구성, 도메인 기능, 공통 UI의 책임을 분리하고 검색·조회·폼 처리 로직을 공통 훅으로 구성했습니다. 서버 상태와 화면 상태의 관리 기준을 정리하고, 사용 가이드·코드 리뷰 기준과 작업 범위·일정 조율을 통해 팀 개발을 지원했습니다.

### 데이터 처리와 보고 자동화

환경 데이터의 API 파싱·저장·기간별 집계를 확장하고, 결측 시간대와 연속 결측 구간을 조회하는 SQL을 구현했습니다. 결측 이력 저장과 메일 발송 정책을 구분하고 HTML·Excel 보고서 생성 기능을 개발했습니다.

### 기존 시스템 분석과 기능 개선

Java/Spring MVC와 JSP 기반 시스템에서 인증·접근 권한, 검색·페이지네이션, 채용 지원, 파일 처리 기능을 개발·보완했습니다. 기존 기능과 직접 변경한 범위를 구분하며 화면·서버·SQL 사이의 연결 오류와 운영 예외를 해결했습니다.

## 대표 프로젝트

- **상가 운영·관리 플랫폼:** React 공통 구조 설계와 결제·창고 예약·계약·알림 도메인 개발.
- **환경보건 데이터 플랫폼:** 수집·집계 확장, 실내공기질 모니터링·통계, 결측 이력과 보고 자동화.
- **어린이집 환경 모니터링:** 센서 결측 대응, 장비 변경 이력, 수신 상태 표시와 조회 SQL 개선.
- **기업 홈페이지:** 다단계 채용 지원서와 가변 입력 항목, 문의·투자정보 및 영문 페이지 개발.
- **기업 운영 관리자 시스템:** 역할별 접근 제어, 업무별 검색, 채용 결과 메일 작성·발송 기능 개발.
