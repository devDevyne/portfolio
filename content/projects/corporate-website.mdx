# 기업 홈페이지 및 온라인 채용

회사 소개, 사업 실적, 투자정보, 고객 문의와 온라인 채용을 제공하는 기업 홈페이지 개발·유지보수에 참여했습니다. Java/Spring MVC 기반 서버 기능과 JSP 화면을 연결하고 영문 페이지를 구성했습니다.

- **담당 역할:** 백엔드 개발, JSP·JavaScript 연동, 영문 페이지 구성, 후속 기능 수정.
- **기록상 작업 기간:** 초기 개발 2023.09, 후속 유지보수 2023.12–2025.05. 연속 투입 기간을 뜻하지 않습니다.
- **공개 범위:** 고객·회사·서비스명은 익명화했습니다.

## 프로젝트 개요

정보 제공 화면과 함께 채용 지원·문의 접수처럼 입력값을 저장하고 이후 상태를 이어가는 업무 기능을 구현했습니다. 특히 지원서의 여러 단계, 가변 개수의 입력 항목, 최종 제출과 접수 안내를 화면·서버·DB에 연결했습니다.

## 모듈별 요약

- **온라인 채용:** 공고 조회, 단계별 지원서 저장·수정, 사진 업로드, 최종 제출과 접수 완료 이메일.
- **사업 실적·투자정보:** 유형별 목록·상세 조회, 페이지네이션, 첨부 다운로드와 공고일 표시.
- **문의·본인인증 연동:** 고객 문의 저장, 초기 제보 기능의 인증 결과 조회와 이메일 전송.
- **국·영문 페이지:** 국문 메뉴와 영문 전용 JSP·라우팅, 팝업·파일 다운로드·PDF 표시 보완.

## 주요 작업

### 1. 다단계 입사지원 흐름 구현

**문제:** 지원자가 여러 단계에 걸쳐 정보를 작성하고 저장한 내용을 다시 불러와 수정·제출할 수 있어야 했습니다.

**고려사항:** 화면 이동뿐 아니라 각 단계의 저장·조회와 최종 제출 상태를 서버 데이터에 연결해야 했습니다.

**담당 작업:** 기본정보, 학력·자격증·경력·수상, 자기소개서, 확인·제출의 4단계 화면과 서버 처리를 구현했습니다.

**기술적 접근:** Controller–Service–DAO–MyBatis에 지원서 조회·등록·수정 처리를 연결했습니다. 사진 업로드와 조회, 최종 제출 상태 갱신 및 접수 완료 이메일 전송을 구성했습니다.

**결과:** 지원서 작성부터 저장·재조회·수정·최종 제출까지 이어지는 업무 흐름을 구현했습니다.

### 2. 가변 입력 항목의 변경을 서버에 반영

**문제:** 지원자마다 자격증·직장경력·수상내역의 개수가 다르고, 저장한 항목을 수정하거나 삭제할 수 있어야 했습니다.

**고려사항:** 화면에서 새로 추가한 행과 기존 저장 행을 구분하고 동적으로 생성한 행에도 삭제 동작을 연결해야 했습니다.

**담당 작업:** 입력 행 추가·삭제 UI와 항목별 등록·수정·삭제 처리를 구현했습니다.

**기술적 접근:** jQuery 이벤트 위임으로 동적 행의 이벤트를 처리하고, 행 식별자와 입력 인덱스를 전달해 신규·기존·삭제 항목을 구분했습니다. 입력 행 수 제한과 추가 경력 행의 날짜 입력도 보완했습니다.

**결과:** 지원자가 항목 수를 조절하고, 저장 이후의 변경을 서버와 DB에 반영할 수 있도록 연결했습니다.

### 3. 반복 클릭에 따른 제출 재실행 제어

**문제:** 서버로 이동하기 전에 제출 버튼을 반복 클릭하면 제출 함수가 여러 번 실행되는 문제가 기록되어 있었습니다.

**고려사항:** 입력 검증을 통과한 시점부터 현재 제출의 진행 상태를 구분해야 했습니다.

**담당 작업:** 채용·문의·제보의 6개 입력 화면에 제출 상태 플래그를 적용했습니다.

**기술적 접근:** 검증 통과 후 제출 상태를 설정하고 이후의 동일 화면 제출 호출은 종료하도록 수정했습니다.

**결과:** 브라우저에서 진행 중인 제출의 재실행을 차단하도록 보완했습니다. 이 작업의 범위는 화면의 반복 제출 제어이며 서버·DB 차원의 멱등성 보장과는 구분합니다.

### 4. 투자정보와 영문 페이지 구성

**문제:** 사업 실적·투자자료를 유형별로 조회하고, 공고일 표시 및 페이지 요청 기준을 서버와 맞춰야 했습니다.

**고려사항:** 등록일과 공고일을 구분하고, 화면이 전달하는 페이지 파라미터를 서버 필드에 일치시켜야 했습니다.

**담당 작업:** 사업·투자정보 조회를 구현하고 공고일 바인딩과 페이지 파라미터를 수정했습니다. 영문 전용 JSP와 라우팅도 추가했습니다.

**기술적 접근:** 유형별 MyBatis 조회 결과를 JSP에 전달하고, 목록·상세·첨부 다운로드를 연결했습니다.

**결과:** 유형별 자료 조회와 영문 페이지 접근을 구성하고, 확인된 날짜 표시·페이지 이동 불일치를 보완했습니다.

## 상세 내용 및 설계 자료

홈페이지 전체 디자인·퍼블리싱, 전체 DB 설계, 관리자 시스템 전체 개발은 이 프로젝트의 기여로 포함하지 않았습니다. 초기 제보 기능은 이후 다른 작성자의 개편과 구분했으며, 영문 작업은 전용 페이지·라우팅 구성 범위입니다.
